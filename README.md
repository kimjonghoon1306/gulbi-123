# 굴비가게 관리시스템 — 최종 정리본

## 🎯 이번 버전 핵심

**AI 상세페이지 = 캔바처럼 단순**

1. **사진 여러 장 업로드** (최대 10장)
2. **GPT-4o가 자동 판단해서 적절한 섹션에 배치**
   - 조리 사진 → 조리법 섹션
   - 원재료 사진 → 원산지 섹션
   - 포장 사진 → 배송 섹션
   - 어울리는 사진이 없는 섹션 → **도형·숫자·텍스트로 자동 대체**
3. **중복 절대 없음** — 같은 이미지가 두 번 안 들어감
4. **틀린 부분만 수정** — 텍스트 탭해서 고치고, 엉뚱한 이미지는 ✕ 눌러 삭제

## 📱 사용법 (모바일 최적화)

### 상세페이지 만들기

1. 상품관리 페이지 → **✨ AI 상세페이지** 버튼
2. **① 사진 업로드** — 사진 여러 장을 한 번에 선택 (갤러리에서 복수 선택)
   - 상품 본체 사진 (필수 1장)
   - 조리 사진 (있으면 조리법 섹션에 자동 들어감)
   - 원재료/산지 사진 (있으면 원산지 섹션)
   - 포장 사진 등
3. **② 상품 정보** — 이름, 가격, 재고 + 글 톤 선택 (쇼호스트/할머니/전문가/부모)
4. **✨ 상세페이지 생성** → GPT-4o가 이미지 분석 + 카피 생성 (30초~60초)
5. **③ 확인 · 수정**
   - **텍스트 탭** → 바로 커서 들어가서 수정
   - **엉뚱한 이미지는 ✕ 버튼** 눌러 삭제 → 해당 섹션이 자동으로 도형+텍스트 버전으로 바뀜
   - **↶ 되돌리기** / **↷ 다시** 버튼 (PC에서는 Ctrl+Z / Ctrl+Y)
6. **🛍️ 상품 등록하기**

### 도형 fallback이 적용되는 섹션
- **보관법** — ❄️ + 큰 강조 온도 + 번호 리스트
- **조리법** — 번호 원형 배지 + 단계 카드
- **특징** — 카드 그리드 (숫자 배지 + 제목 + 설명)
- **원산지 통계** — 2x2 인포그래픽 카드

## 🔧 주요 변경사항

### 편집 버그 수리
- **텍스트 수정 안 되던 문제**: `dangerouslySetInnerHTML` 제거, `useEffect`로 초기 1회만 주입
- **커서 사라지던 문제**: React 리렌더가 DOM을 덮어쓰지 않음
- **입력한 글이 원복되던 문제**: innerHTML은 사용자 편집 후 건드리지 않음

### 모바일 편집 최적화
- 풀스크린 모달 (스크롤 영역 고정 높이)
- 하단 버튼은 safe-area-inset 처리 (아이폰 홈 인디케이터 피함)
- 텍스트 더블탭 확대 방지
- 편집 영역 탭 하이라이트 핑크톤
- 숫자 입력은 `inputMode="numeric"` (숫자 키패드 뜸)

### 불필요한 기능 제거
- Unsplash 검색 (한국 상품은 의미 없음)
- DALL-E AI 이미지 생성 (가짜 이미지는 신뢰도 ↓)
- 자동 보정 / 씬 카테고리 / ImagePicker 3탭 UI
- 도형·아이콘 삽입 툴바 (EditorToolbar) — 도형은 AI가 자동 배치
- 섹션 클릭 감지 / 삽입 위치 토글

### Next.js 설정
- `typescript.ignoreBuildErrors` 제거 — 진짜 에러는 숨기지 않음
- `serverActions.bodySizeLimit: '20mb'` — 10장 이미지 업로드 여유

## ⚠️ 알려진 제약

- **GPT-4o 응답 시간**: 이미지 많을수록 오래 걸림 (10장이면 60초까지 가능)
- **토큰 비용**: 10장 업로드 시 한 번 생성에 약 $0.15~0.30
- **되돌리기**: 최대 40단계, 새 상세페이지 생성하면 초기화
- **수동 상세페이지 업로드**: 이 버전에서 수동 HTML 직접 붙여넣기 기능 없음 (필요하면 추후 추가)
